# Copia publica do codigo-fonte

Esta copia foi preparada sem historico Git, arquivos .env reais, configuracoes locais de IDE/SDK, caches, backups, bancos de dados, seeds operacionais, pacotes de release e arquivos binarios (incluindo fotos, videos, audio, logos e icones). Enderecos do servidor foram substituidos por example.com; configuracoes devem ser preenchidas localmente.

Para publicar, extraia este ZIP em uma pasta nova e crie um repositorio novo a partir dela. Nao reutilize o diretorio .git do projeto original.

Para executar o Flutter, copie app_flutter/.env.example para app_flutter/.env e configure seu backend. Reponha os recursos graficos e sons referenciados pelo projeto com arquivos que voce possa publicar. O wrapper binario Gradle e os arquivos gerados devem ser regenerados com as ferramentas de desenvolvimento. As APIs PHP dependem da conexao e do backend configurados separadamente. Regere pacotes e hashes das releases antes de distribuir o player.

Esta e uma distribuicao de codigo-fonte para publicacao, nao um pacote pronto para execucao. Os arquivos originais nao foram alterados.
